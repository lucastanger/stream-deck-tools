# README screenshots

These PNGs are actual captures of the Stream Deck desktop editor, cropped to the
project's controls/settings. They are not mockups, simulated plugin states, or
photographs of physical hardware.

- `stream-deck-controls.png`: the microphone, camera, and reaction keys in the
  Teams folder on a Stream Deck Neo layout. No meeting controls were accessible
  at capture time, so their true state was **Unknown**.
- `reaction-settings.png`: the installed plugin's per-key reaction dropdown,
  showing Like, Love, Applause, Laugh, and Surprised. Opening this configuration
  dropdown does not send a meeting reaction.

Only cropping and fresh PNG encoding were applied. No status labels, icons,
colours, or options were altered. Account details, desktop windows, meeting
content, and unrelated app panels were excluded. Original uncropped captures
are intentionally not part of the repository. Embedded source metadata is not
copied into the published PNGs.

For future active-state captures, use a private test meeting, obtain any needed
consent, and capture the Stream Deck editor only. Describe the actual observed
states; never substitute mock data or change a meeting control solely to make a
screenshot look safer than its real state. Review every crop for personal data
before committing it. Keep image captions/alt text accurate when replacing them.
